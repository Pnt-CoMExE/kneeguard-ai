Topic

What we will build

An AI decision-support system that estimates probabilities for 12 clinically important knee abnormalities from MRI studies, then helps radiologists prioritize review (triage).

Application area

  • Healthcare / medical imaging AI
  • Musculoskeletal (MSK) radiology
  • Multilabel classification + decision support

Course framework

  • Problem → Dataset → Data Model
  • AI Model → Decision → Action
  • Today we present only the Problem stage
Problem context

What is happening?

  • A single knee MRI can reveal multiple abnormalities at once (ligaments, meniscus, OA, effusion, fracture, and more).
  • Interpretation quality varies across sites and readers.
  • Access to specialty-trained MSK radiologists is limited in many healthcare settings.
  • High-risk findings (e.g., fracture, ACL injury) may be delayed in a large reading queue.
Current limitation: the process depends heavily on expert reading, which is hard to scale consistently.
Decision problem

Problem statement

The proposed model will help radiologists and triage teams classify clinically important knee abnormalities by using multimodal knee MRI series and (training-time) radiology report text.

Decision needed

  • Which studies should be reviewed first?
  • Which findings need urgent attention?

How AI helps

  • Outputs 12 finding probabilities
  • Maps scores to Low / Medium / High triage
  • Human confirmation remains required
Stakeholders

Who is involved?

Stakeholder Role Information / decision needed
MSK radiologist Decision maker Prioritized worklist + per-finding probabilities
ER / orthopaedic clinician Care provider High-risk flags (fracture, ligament injury)
Hospital / imaging IT System operator Runtime, audit trail, safe deployment constraints
Patient Affected party Faster and more consistent care pathway
Justification

Why this problem is worth solving

  • Clinical complexity: multilabel findings in one exam require simultaneous detection.
  • Workforce gap: MSK specialist expertise is unevenly distributed.
  • Patient impact: delayed high-risk findings can affect treatment timing.
  • Feasible dataset: RSNA/Kaggle public competition data (~5,000+ exams, multi-site, multilingual reports).
  • Clear decision use-case: triage support with human-in-the-loop oversight.
Direction

Objectives & project questions

Objectives

  • Examine relationships between MRI studies and 12 abnormality labels
  • Develop a multilabel model for per-finding probabilities
  • Translate outputs into triage decision rules with human oversight

Key questions

  • Which features matter most for each finding?
  • Which model best supports multilabel detection?
  • How do we convert probabilities into practical actions?
  • How should success be evaluated?

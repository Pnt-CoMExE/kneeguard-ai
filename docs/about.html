Project context

This project is a course mockup for 1501418 Selected Topics in Data Science and AI. The topic is based on the RSNA 2026 Knee Abnormality Detection Kaggle competition hosted by the Radiological Society of North America.

This site does not contain a trained model or real patient data. All probabilities in the demo are simulated values for UX prototype purposes only.

AI Use Disclosure: Generative AI tools were used during the development of this mockup website. All content, code, and analytical judgements have been reviewed and verified by the group. Add specific AI tool names used, if applicable.

Submission checklist

  • Clearly defined real-world problem
  • Evidence supporting importance of the problem
  • Identified stakeholders and decision requirements
  • Clear objectives and project questions
  • Reliable and properly cited dataset
  • Complete data dictionary
  • Data quality and preprocessing analysis
  • At least three meaningful data visualizations
  • Clear data model / pipeline
  • Justified decision-model approach
  • Evaluation measures and success criteria
  • Decision rules connecting outputs to actions
  • Proof-of-concept or demonstration
  • Benefits, limitations, ethics, and risks discussed
  • Individual contribution statement for every member
  • Complete references in APA 7th edition
